## What's New

### Major Features

#### Multi-Destination Backup
- Parallel backup to local + multiple remote targets simultaneously
- Supports SFTP + WebDAV + S3 cloud storage in a single operation
- Independent failure handling per destination

#### S3 Cloud Storage
- AWS S3 compatible storage support (AWS, MinIO, Alibaba Cloud OSS, etc.)
- Upload/download/delete operations
- Auto-create bucket if not exists

#### Data Integrity
- SHA256 checksum generation and verification
- Reed-Solomon error correction codes (reedsolo)
- Tamper detection with HMAC validation

#### Task Queue System
- JSON-persistent task queue management
- Add, execute, cancel, delete tasks
- Async background execution with status tracking

#### Cross-Archive Search
- Search for files across multiple backup archives
- Pattern matching with wildcard support
- Results grouped by archive

#### Selective Restore
- Restore specific files matching patterns
- Keyword-based file extraction
- Dry-run preview before actual restore

#### Backup Rotation
- Keep-count policy: retain latest N backups
- Keep-days policy: retain backups within N days
- Keep-daily policy: retain N daily backups

#### Pre/Post Hooks
- Execute custom commands before/after backup
- Timeout control and error handling
- Cross-platform command parsing

#### Configuration Profile
- Save/load/delete named profiles
- Switch between different backup configurations
- Import/export profiles as JSON

#### Audit Logging
- Record all backup/restore operations
- Search by time range and event type
- JSON-persistent audit trail

### Performance & Reliability

- **Chunked Backup**: 64KB block-level incremental backup
- **File Deduplication**: SHA256-based dedup to avoid redundant uploads
- **Parallel Compression**: Multi-threaded compression for large backups
- **Bandwidth Limiter**: Token bucket rate limiting for remote uploads
- **Retry Mechanism**: Exponential backoff for network operations
- **Backup Lock**: Cross-platform process lock to prevent concurrent runs

### Remote Backup Enhancements

- **SFTP**: Auto-detect default SSH keys (~/.ssh/id_rsa, id_ed25519)
- **SFTP**: Host key verification with known_hosts
- **SFTP**: Allow password fallback on private key auth failure
- **WebDAV**: Zero-dependency urllib implementation
- **WebDAV**: SSRF protection (protocol/IP validation)
- **WebDAV**: Proper PROPFIND redirect handling
- **S3**: MinIO client with path prefix support

### Security

- PBKDF2 encryption for sensitive config fields
- HMAC-SHA256 config tamper detection
- SSRF protection for WebDAV and webhook URLs
- Safe archive extraction (path traversal prevention)
